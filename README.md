# Monitoramento da Crise Hídrica

Projeto de monitoramento dos níveis dos rios em Rondônia, com dados da Agência Nacional de Águas e Saneamento Básico (ANA).

Estações monitoradas: Ji-Paraná, Porto Velho, Ariquemes e Guajará-Mirim.

Fonte: [Séries históricas do HidroWeb](https://www.snirh.gov.br/hidroweb/serieshistoricas).
